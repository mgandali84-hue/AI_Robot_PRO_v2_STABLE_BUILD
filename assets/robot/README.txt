AI Robot PRO v2 Lip Sync asset

ai_robot_pro_v2_lipsync.glb:
- real GLB model
- morph targets on mouth mesh: MouthOpen, MouthWide, MouthRound
- animation clips: Mouth_Closed, Mouth_A, Mouth_E, Mouth_O
- body/idle/listening/thinking/speaking/happy animations from the base robot

Flutter maps TTS progress words to mouth animations. This is a practical text-derived
phoneme heuristic. It is not a full acoustic phoneme neural recognizer.
